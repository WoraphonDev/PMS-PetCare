# T-0022-02 · How does the installed PWA pick up a new version?
- Status: answered
- Raised by: claude · T-0022 (card preparation; revised after review) · 2026-10-24
- Context:
  - pms-web is a PWA (ADR-0001) used on shared shop tablets/phones, often left open all day, with forms staff are filling in (bookings, check-in later).
  - `vite-plugin-pwa` offers `registerType: "autoUpdate"` (new service worker activates and the page **reloads by itself**) or `"prompt"` (the app is told an update is waiting and shows something to the user).
  - A prompt needs a small UI element and Thai text, which §7 does not define. Per AGENTS rule 3 the card must not invent it.
  - Staying on an old build for long is also a risk: the API contract can move on (deploys go to staging automatically, production after approval — T-0032).
- Question: Which update behaviour, and if a prompt, what does it say?
- Options:
  (A) **Prompt banner:** when an update is waiting, a non-blocking bar at the bottom: "มีเวอร์ชันใหม่" with a button "อัปเดต" (reloads into the new version) — no dismiss button, so it stays until tapped. Never reloads by itself, so an update never interrupts a form on its own. Pressing "อัปเดต" does reload, so unsaved form data on the open page **can** still be lost if the user presses it mid-form (no draft saving in this card). Strings live in i18n `common`.
  (B) **Auto update:** the new version activates and the page reloads as soon as it is downloaded. No UI, always current, but can wipe a form being filled in.
  (C) **Auto update on next navigation:** activate silently, and reload only on the next route change (not in the middle of a page). No UI; small chance of losing state held across routes.
  — แนะนำ: A. B can wipe a form with no warning, and C can still surprise staff; with A the reload happens only when the user chooses it (the user can finish the form first). A persistent bar is the common PWA pattern and needs two short strings. Wording is a product choice — change it in the answer if you prefer other text.
- Answer: 2026-10-24 · Zo chose (A) via Friday: prompt banner "มีเวอร์ชันใหม่" with button "อัปเดต", no dismiss, never reloads by itself; pressing the button reloads into the new version (unsaved form data on that page can still be lost). Strings in i18n `common`. Card: T-0022.
