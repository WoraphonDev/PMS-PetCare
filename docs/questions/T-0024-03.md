# T-0024-03 · PWA build test's `/runtime/` matches a chunk file name (`jsx-runtime-*.js`), not a runtime-caching route
- Status: answered
- Raised by: claude · T-0024 · 2026-10-24
- Context:
  - `apps/pms-web/test/build/pwa-build.test.ts` (T-0022) "registers exactly one route…" asserts `expect(sw).not.toMatch(/runtime|NetworkFirst|CacheFirst|StaleWhileRevalidate/)` on `sw.js`. The intent is "no Workbox runtime caching".
  - With T-0024's shell (an `_app` layout chunk that shares React with the entry), Rolldown emits a shared chunk named `assets/jsx-runtime-<hash>.js` in the test-mode build (`NODE_ENV=test`, dev React). Its file name appears in the precache manifest inside `sw.js`, so the bare word `runtime` matches. The service worker still registers exactly one route (the `NavigationRoute`) and no caching strategy; the production build (`pnpm build`) does not emit that chunk name.
  - Verified: on `origin/main` the same build puts `jsx-runtime` in the shared `i18n` chunk; moving T-0024 code around (`useQuery` placement, `QueryClientProvider` in `__root`) did not change Rolldown's choice. The chunk name is a bundler heuristic, not something this card controls.
  - The test file is outside T-0024 `allowed_paths` (`test/shell/**` only), so the branch leaves it untouched.
- Question: How should the PWA build test tell "runtime caching" apart from a chunk file name?
- Options:
  (A) **Add `apps/pms-web/test/build/pwa-build.test.ts` to T-0024 `allowed_paths`** and match Workbox's runtime-caching API instead of the bare word: `not.toMatch(/\bNetworkFirst\b|\bCacheFirst\b|\bStaleWhileRevalidate\b|\bNetworkOnly\b|\bCacheOnly\b|runtimeCaching/)` plus the existing "exactly one `registerRoute`" check. Same intent, no false positive on file names.
  (B) Same file, but strip the precache manifest (`precacheAndRoute([...])` argument) from `sw` before the regex, keeping `/runtime/` as is.
  (C) Change `vite.config.ts` to name chunks so no file contains `runtime` (e.g. `build.rolldownOptions.output.chunkFileNames`). Touches build config for a test artefact; another card's chunk could reintroduce it.
  — แนะนำ: A. Fixes the false positive at its source and is stricter than today (catches every Workbox strategy, not one word).
- Answer: 2026-10-24 · human chose (A) in chat ("ตอบ A ทั้งหมด"). `apps/pms-web/test/build/pwa-build.test.ts` is added to T-0024 `allowed_paths` (separate docs PR, human merge); the regex matches Workbox strategy names / `runtimeCaching` instead of the bare word `runtime`.
