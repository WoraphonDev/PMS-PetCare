# T-0043-02 · Biome cannot parse Tailwind v4 CSS (`@theme`, `@source`) — enable `tailwindDirectives` in root `biome.json`?
- Status: answered
- Raised by: claude · T-0043 · 2026-10-24
- Context:
  - T-0043 asks for "Tailwind v4 tokens in one `styles.css` the app imports". In Tailwind v4, design tokens are declared with `@theme { --color-primary: … }`; the app must also tell Tailwind to scan the workspace package's classes with `@source` (a symlinked workspace package under `node_modules` is not auto-detected).
  - Root `biome.json` (Biome 2.5.15) lints `**` except docs/migrations/… . Its CSS parser rejects `@theme` and `@source` as parse errors (`packages/ui/src/styles.css:6:2 parse`, `:8:2 parse`), so `pnpm lint` / `pnpm verify` fail. Parse errors cannot be suppressed with `biome-ignore`.
  - Biome supports these with `"css": { "parser": { "tailwindDirectives": true } }` — checked locally: with that setting the same file parses (only formatting remains, which `biome check --write` fixes).
  - `biome.json` is outside T-0043's `allowed_paths`, and since #68 a nested `biome.json` in a client workspace is forbidden (`scripts/test/import-boundaries.test.mjs`). T-0022's app CSS (`@import "tailwindcss"` + `@source`/`@theme inline`) will hit the same error.
- Question: How should Tailwind v4 CSS pass `pnpm verify`?
- Options:
  (A) **Human adds one setting to root `biome.json`:** `"css": { "parser": { "tailwindDirectives": true } }` in a small process PR (or allows T-0043 to touch `biome.json` for exactly this key). Merged before T-0043; T-0043 then keeps `@theme` tokens in `packages/ui/src/styles.css` as the card says, and T-0022 needs nothing extra.
  (B) Exclude CSS from Biome (`"!**/*.css"` in root `files.includes`). Also a root change, and loses formatting/lint for all CSS.
  (C) No Tailwind directives in `packages/ui`: `styles.css` holds plain `:root { --primary: … }` variables, and the `@theme inline` mapping moves to the app (T-0022). Still needs (A) or (B) for the app's CSS, and splits the tokens over two packages, contrary to the card.
  — แนะนำ: A. One documented Biome option, keeps lint on CSS, and unblocks both T-0043 and T-0022.
- Answer: 2026-10-24 · human chose (A) via PR #71: root `biome.json` sets `"css": { "parser": { "tailwindDirectives": true } }`, guarded by `scripts/test/tailwind-css.test.mjs` (CSS still parsed, not excluded). `packages/ui/src/styles.css` keeps the `@theme` tokens and `@source`.
