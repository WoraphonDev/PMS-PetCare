# T-0019-02 · platform.org.setStatus: reason, no-op, response and audit visibility
- Status: open
- Raised by: claude · T-0019 (card preparation) · 2026-10-23
- Context:
  - foundation#ep-platform.org.set_status: `PUT /platform/orgs/{orgId}/status` · platform admin · `{ status, reason }` · audit `platform.org_status_changed`.
  - F04: a suspended org can read, every write → `ORG_SUSPENDED` (except `platform.*`). `organization` has `status` but **no column for the reason**.
  - #tbl-audit_log: `org_id` null = platform-level event. `audit.list` (T-0018) shows the shop owner only rows with the shop's `org_id`.
  - Not defined:
    - `reason` limits;
    - where the reason is kept;
    - what an unchanged status does;
    - the response;
    - which `org_id` the audit row carries, which decides whether the shop owner sees the suspension and its reason;
    - whether sessions or pending invitations are touched.
- Question: What does setStatus accept, write and return, and who can see the audit row?
- Options:
  (A) Strict body:
    - `status` ∈ `active`/`suspended`;
    - `reason` trimmed 1–500, required;
    - unknown org → `NOT_FOUND`; malformed id/body → `VALIDATION_FAILED`.
    In one transaction (org row locked):
    - status unchanged → 200, nothing written;
    - otherwise set `status`, `updated_at`, and write the audit row `platform.org_status_changed`: `org_id` = **the target org**, actor = admin, `entity_type 'organization'`, `entity_id` = org id, `before { status }`, `after { status, reason }`. The reason lives only in the audit row, and the shop owner sees it in `audit.list`.
    - No sessions or invitations are changed (F04 already blocks writes).
    - Response 200 = the platform org detail (T-0019-01).
  (B) Same as A, but the audit row has `org_id` null (platform-only; the owner does not see why the shop was suspended).
  (C) Same as A, but `reason` is optional when re-activating.
  — แนะนำ: A. A suspended shop sees a banner (F04) and needs to know why; the owner's audit log is the place for it. If reasons may contain internal remarks, choose B and tell shops the reason another way (out of scope).
