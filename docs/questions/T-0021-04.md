# T-0021-04 · Audit of the relay's platform-connection writes (`published_at`, `attempts`)
- Status: answered
- Raised by: claude · T-0021 (card review) · 2026-10-24
- Context:
  - ADR-0003: "งานข้ามร้าน (platform admin, Marketplace read model) ใช้ role/connection แยกและเขียน `audit_log`". The relay uses the platform connection (`app_platform`, BYPASSRLS) — migration 0004 lets only that role read/update `outbox_event` — and it updates `published_at` and `attempts` across all shops.
  - foundation §6 lists every audit action; none covers outbox delivery, and agents must not invent one (AGENTS rule 3). `audit_log.actor_user_id` null means "system" (#tbl-audit_log).
  - These writes change no business data: they record delivery state of rows the API already wrote and audited where the spec requires it (e.g. `branch.created` is both audited and an outbox event).
  - Auditing each relay write would add one `audit_log` row per event per poll attempt — mostly noise, and growing faster than the outbox itself.
- Question: Must the relay's `published_at` / `attempts` updates write `audit_log`, or are they an approved exemption?
- Options:
  (A) **Exempt, recorded by a human in ADR-0003 (or the spec):** system delivery bookkeeping on `outbox_event` (`published_at`, `attempts`) is not "งานข้ามร้าน" in the ADR's sense and writes no audit row; the worker's structured logs (T-0021-01) are the operational record. A human makes that one-line ADR/spec amendment in a separate PR before T-0021 starts. T-0021 then asserts no audit row is written.
  (B) **Audit with a new system action** (e.g. one row per relay batch, actor null). Needs a human-approved §6 amendment naming the action, `entity_type`, `org_id` rule (the batch spans shops) and before/after content, then tests.
  (C) **Exempt without changing documents** — rely on this answer file only. Fastest, but the ADR text keeps saying the opposite, and a later reviewer will flag it again.
  — แนะนำ: A. It matches the ADR's purpose (accountability for cross-shop data access by people and read models) without auditing machine bookkeeping, and it keeps the ADR and code consistent. The amendment is a human edit; the T-0021 agent must not make it.
- Answer: 2026-10-24 · Zo chose (A) via Friday: exemption **only** for outbox delivery bookkeeping — the worker's updates of `outbox_event.published_at` and `outbox_event.attempts` write no `audit_log` row. Every other platform-connection write keeps the ADR-0003 rule. No new audit action. Recorded in the ADR-0003 amendment (separate human-merged PR); T-0021 tests that the relay writes no audit row.
