## Goal

## Design

### Money formatting — added to `src/lib/format.ts`

The date helpers (`formatDate`, `formatDateTime`, `bangkokDayStartUtc`) already exist from T-0024; this card adds:


- `formatBaht(satang: number)`: integer satang → `฿1,290` / `฿1,290.50` (`th-TH`, no float arithmetic on the stored value — divide only for display via integer `/100` and `%100`); `0` → `ฟรี`.

### `scr-audit` — `/settings/audit` (owner)

- Filters: date range (from / to local dates → `from` = start of the from-day, `to` = start of the day **after** to-day, both via `bangkokDayStartUtc`; either may be empty; client check ≤ 366 days and from ≤ to), action (select of the 16 §6 actions with Thai labels), person (select from `staff.list` members + "ทั้งหมด"; owner has `staff.read`).
- `GET /audit-logs` → table: time, person (`actor.displayName`, `null` → "ระบบ"), action label, target (`entityType` label), changes. "โหลดเพิ่ม" uses `nextCursor`; changing a filter restarts from the first page.
- Changes column: for each key in `after ∪ before` show `key: before → after` (values rendered as text; arrays joined; `null` → "—"). Keys shown as received (no translation table for field names in MVP).
- Empty → `empty`. `VALIDATION_FAILED` (bad cursor/range) → reset filters message. Non-owner opening the URL → `errors.FORBIDDEN` text, no request. Readable while suspended.

### `scr-subscription` — `/settings/subscription` (owner, manager)

- `GET /subscription` → plan name and code, price per month (`formatBaht(priceSatangPerMonth)` + "/เดือน"), started (`startedAt`), period end (`currentPeriodEnd` or `noPeriodEnd`), usage rows: สาขา `usage.branches / maxBranches`, พนักงาน `usage.staff.total / maxStaff` with the breakdown active + pending invitations; `null` max → `unlimited`; a bar per row; row at/over the limit highlighted with `atLimit`.
- No buttons (plan changes are done by the platform admin — T-0028). Text `contactToChange`.
- Readable while suspended.

## Tests (write first)

- `formatBaht`: 0 → ฟรี, 99000 → ฿990, 129050 → ฿1,290.50, large values; never produces float artefacts (e.g. 1999 → ฿19.99).
- audit date filter: to-date is sent as the start of the next Bangkok day (exclusive).
- audit: query keys only those set; range > 366 days blocked; `null` actor → ระบบ; action labels for all 16 actions (a test fails if §6 gains an action without a label — compare with the contract's enum); changes rendering; load more appends and stops when `nextCursor` null; filter change restarts; non-owner → forbidden text, no request.
- subscription: price/free; `null` max → ไม่จำกัด; staff total = active + pending shown with breakdown; at-limit highlight; `currentPeriodEnd` null → ไม่มีวันหมดอายุ; manager can view.
