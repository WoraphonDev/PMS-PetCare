## Tests (เขียนก่อน)

- full HTTP signup → exactly user/account/current verification/org/branch/7 hours/active owner/mvp_free subscription; zero signup session/cookie; verified login only after consume
- validation boundaries password 10/128/not trimmed; names trimmed 1/100 Unicode vs char_length; slug exact regex; email normalization matches pinned auth/login and historical preflight
- duplicate email native synthetic-success deliberately exercised → CONFLICT no second tenant; parallel same email/different slug and same slug/different email exactly one committed bootstrap
- duplicate known constraint → CONFLICT; unknown constraint/DB/Valkey failure → INTERNAL; sixth valid attempt → RATE_LIMITED; malformed → VALIDATION_FAILED no quota; conflicts count
- inject error identity/account/verification/org/branch/each hours/membership/subscription/commit → no residual records/messages; no-context/wrong-org RLS failures; same-PID pooled context clears
- sender failure after commit retains 201 and rows; recovery resend works; concurrency collector isolation/no token/PII logs; no native session even when supplied cookie
- public endpoint has no tenant resource/role check; isolation verified in helper tests instead of invented NOT_FOUND/FORBIDDEN errors
