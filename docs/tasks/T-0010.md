# T-0010 · 2FA

## Goal

ผู้ใช้เปิด 2FA ได้เอง; platform admin **ต้อง** ผ่าน 2FA ก่อนเรียก `platform.*` (F10)

## Read first

- `docs/spec/features/foundation.md#rule-F10`, `#ep-auth.two_factor.verify`, `#ep-auth.two_factor.enable`, `#ep-auth.two_factor.disable`, `#ep-auth.login`, `#errors`
- `docs/spec/features/foundation.md` §6 (audit `auth.two_factor_enabled` / `auth.two_factor_disabled`)

## Deliverables

- Better Auth plugin `twoFactor` (TOTP, backup codes 10 ชุด, trust device 30 วัน)
- `auth.twoFactor.enable` / `.verify` / `.disable` ตาม spec; `auth.login` ตอบ `twoFactorRequired: true` เมื่อเปิด 2FA และ session อยู่ในสถานะรอ verify (เรียก endpoint อื่นไม่ได้ → `UNAUTHENTICATED`)
- platform admin ปิด 2FA ไม่ได้ → `FORBIDDEN`
- `apps/api/src/common/platform-admin.guard.ts`: `is_platform_admin` + session ผ่าน 2FA แล้ว; ยังไม่ผ่าน → `TWO_FACTOR_REQUIRED`; ไม่ใช่ admin → `FORBIDDEN`
- audit ใน transaction เดียวกับการเปิด/ปิด
- TOTP secret / backup code ห้ามอยู่ใน log, response (ยกเว้นตอน enable ครั้งแรก) และ audit

## Tests (เขียนก่อน)

- enable → `totpUri` + 10 backup codes; ยังไม่ verify → `two_factor_enabled` ยังเป็น false
- login ของผู้ใช้ที่เปิด 2FA → `twoFactorRequired`; เรียก `/me` ก่อน verify → 401; verify ด้วย TOTP (สร้างจาก secret ใน test ด้วย clock ทดสอบ) → ผ่าน; backup code ใช้ได้ครั้งเดียว
- trust device: login ซ้ำภายใน 30 วันไม่ต้อง verify; หลัง 30 วัน (clock) ต้อง verify
- disable ต้องมีทั้งรหัสผ่านและ code; platform admin → 403
- platform guard: admin ไม่มี 2FA → `TWO_FACTOR_REQUIRED`; ผู้ใช้ทั่วไป → 403
- audit 1 แถวต่อ enable/disable และไม่มี secret ในแถว

## Dependencies

ไม่มี (plugin อยู่ใน `better-auth`)
