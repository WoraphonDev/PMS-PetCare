## Goal

Owner, manager and front desk see the shop's staff and pending invitations; owner and manager invite a person by email or create a username account for staff without email, within the plan's staff limit.

## Design

### `scr-staff` — `/settings/staff` (owner, manager, front_desk read-only)

- `GET /staff` → two sections.
  - **Members** (API order): name, email **or** username (managed: username; email is `null` — never show `@managed.invalid`), role label, branch names (from the branch list; `[]` for org-wide roles → "ทุกสาขา"), 2FA on/off, "บัญชีที่ร้านสร้าง" badge when `isManaged`. Row actions come in T-0047 (leave an actions slot).
  - **Pending invitations**: email, role, branches, expires (`formatDate` from T-0024), revoke button.
- front_desk: same table, no buttons (no `staff.invite`).
- Buttons for `can(role, "staff.invite")` (owner, manager): "เชิญทาง email", "สร้างบัญชี (ไม่มี email)" (labels from §7).
- Role picker in both forms: owner sees all 5 roles; manager sees only `front_desk`, `groomer`, `caretaker` (¹). Branch multi-select shown only for branch roles (required ≥ 1); hidden and sent as `[]` for owner/manager.
- **Invite** dialog: email, role, branches → `POST /staff/invitations` → 201 → refetch + `invited` toast (does **not** say the email was delivered). Re-inviting an email with a pending invitation is allowed (the API replaces it). Errors: `ALREADY_MEMBER`, `PLAN_LIMIT_REACHED` → `limitReached`, `BRANCH_REQUIRED`, `FORBIDDEN` (manager inviting owner/manager, or re-invite over an owner/manager invitation), `NOT_FOUND` (branch gone) → messages; `VALIDATION_FAILED` → fields.
- **Create managed account** dialog: display name, username (`^[a-z0-9._-]{3,40}$` after lowercasing — show lowercased preview), temporary password (10–128) + "show password" toggle, role, branches → `POST /staff/accounts` → 201 → refetch + a panel with the username and the reminder that the person must change the password at first login. The password is not shown again after closing. Errors: `CONFLICT` → `usernameTaken`, `PLAN_LIMIT_REACHED`, `BRANCH_REQUIRED`, `FORBIDDEN`, `NOT_FOUND`.
- **Revoke** with confirm → `DELETE /staff/invitations/{id}` → 204 → refetch; `NOT_FOUND` (already used/revoked/expired) → refetch + `invitationGone`; `FORBIDDEN` → message.
- `ORG_SUSPENDED` on any write → `errors.ts`.
- api-client: `staff.list`, `staff.invite`, `staff.invitation.revoke`, `staff.account.create` in new `endpoints/staff.ts` (+ one export line).
