# T-0006 · Org tables + composite branch FKs

`human_review: true` — ตาราง `plan` / `subscription` มีราคา (`price_satang_per_month`)

## Goal

ตารางที่เหลือของ foundation และกฎ composite FK (Q-0014) — พร้อมสำหรับ signup, staff และ subscription

## Read first

- `docs/spec/features/foundation.md#tbl-branch_hours`, `#tbl-branch_closure`, `#tbl-membership`, `#tbl-membership_branch`, `#tbl-invitation`, `#tbl-plan`, `#tbl-subscription`, `#roles`
- `docs/spec/features/foundation.md#rule-F01`, `#rule-F02`, `#rule-F03`, `#rule-F05`
- `docs/spec/01-conventions.md#database` (กฎของตารางในร้าน)
- `docs/adr/0003-multi-tenancy.md`

## Deliverables

- schema: `branch_hours`, `branch_closure`, `membership` (+ enum `staff_role`, `membership_status`), `membership_branch`, `invitation`, `plan`, `subscription` — คอลัมน์/null/unique/CHECK ตาม spec ทุกตัว
  (`weekday` 1–7, `opens_at < closes_at` หรือ null ทั้งคู่, `start_date <= end_date`, `token_hash` เท่านั้น, `price_satang_per_month` integer ≥ 0)
- `branch`: เพิ่ม `unique (org_id, id)`
- **composite FK** `(org_id, branch_id) → branch (org_id, id)` สำหรับทุกตารางที่มีทั้งสองคอลัมน์ในการ์ดนี้ และเปลี่ยน FK ของ `outbox_event`, `usage_event` ให้เป็นแบบเดียวกัน
- RLS ENABLE + FORCE + `tenant_isolation` ทุกตารางที่มี `org_id` (custom migration); `plan` ไม่มี `org_id` → อ่านได้ทุก role, เขียนได้เฉพาะ `app_platform` (REVOKE INSERT/UPDATE/DELETE จาก `app_runtime`)
- `packages/db/src/seed/plans.ts`: `seedPlans(tx)` idempotent — `mvp_free` (max_branches 1, max_staff 5, price 0, active) ตาม `#tbl-plan`
- export schema + `seedPlans` จาก `src/index.ts`

## Tests (เขียนก่อน)

`packages/db/test/org-tables.test.ts`:
- composite FK: แถวของ org A ที่อ้าง branch ของ org B → FK violation (ทั้ง `branch_hours`, `membership_branch`, `outbox_event`, `usage_event`)
- CHECK ทุกตัวข้างบน (ค่าถูก/ผิด/null)
- unique: `membership (org_id, user_id)`, `branch_hours (branch_id, weekday)`, `subscription (org_id)`
- RLS: org B มองไม่เห็นแถวของ org A ในทุกตารางใหม่ (`rls-coverage.test.ts` ต้องผ่านด้วย)
- `app_runtime` เขียน `plan` ไม่ได้; `seedPlans` รันซ้ำได้โดยไม่ซ้ำแถว
