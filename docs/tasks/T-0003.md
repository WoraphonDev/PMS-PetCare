# T-0003 · packages/db + RLS tenancy harness

## Goal

ฐานของการแยกข้อมูลแต่ละร้าน: Drizzle + migration, ตาราง `organization` / `branch`, Postgres RLS,
helper `withTenant` และ test harness บน Postgres จริง — รวมถึง **gate อัตโนมัติ** ที่ ADR-0006 กำหนด

## Deliverables

- `packages/db/` (`@app/db`)
  - `drizzle.config.ts` (`casing: "snake_case"`, out `migrations/`)
  - `src/schema/org/organization.ts` (+ enum `org_status`), `src/schema/org/branch.ts` — คอลัมน์/ชนิด/null ตรง spec ทุกตัว
  - migration `0000_*` (generate) + custom migration สำหรับ RLS:
    - `organization`: `ENABLE` + `FORCE ROW LEVEL SECURITY`, policy `id = current_setting('app.org_id', true)::uuid`
    - `branch`: `ENABLE` + `FORCE`, policy `USING` และ `WITH CHECK` `org_id = current_setting('app.org_id', true)::uuid`
  - `src/schema/index.ts` re-export ทุก schema; `src/index.ts` re-export public API ของ package
  - `src/client.ts`: `createDb(url)` คืน Drizzle client (node-postgres pool)
  - `src/tenant.ts`:
    - `withTenant<T>(db, orgId: string, fn: (tx) => Promise<T>): Promise<T>` — เปิด transaction แล้ว `select set_config('app.org_id', $1, true)` ก่อนเรียก `fn`
    - `withPlatform<T>(platformDb, fn)` — สำหรับ connection role `app_platform` เท่านั้น
  - scripts: `generate`, `migrate`, `test`, `typecheck`
  - `test/support/test-db.ts`: `createTestDb()` เปิด `postgres:17-alpine` ด้วย Testcontainers (reuse ได้), สร้าง role:
    - `app_migrator` (เจ้าของตาราง, รัน migration)
    - `app_runtime` (`NOBYPASSRLS`, ได้สิทธิ์ `SELECT/INSERT/UPDATE/DELETE` บนตาราง)
    - `app_platform` (`BYPASSRLS`)
    แล้วคืน `{ runtimeDb, platformDb, migratorDb, stop }`
  - `README.md` สั้น ๆ: วิธี generate/migrate และ role ทั้ง 3 (การสร้าง role ใน production เป็นงาน ops แยก)

## Tests (เขียนก่อน)

`packages/db/test/tenancy.test.ts`:
- seed org A, B (ผ่าน `withTenant` ของแต่ละ org) แต่ละ org มี 1 branch
- `withTenant(A)` select branch → เห็นเฉพาะของ A
- `runtimeDb` โดยไม่ตั้ง `app.org_id` → select branch ได้ 0 แถว
- `withTenant(A)` insert branch ที่ `org_id = B` → error (WITH CHECK)
- `withTenant(A)` update branch ของ B → 0 แถวถูกแก้
- `app.org_id` ไม่รั่วข้าม transaction (transaction ถัดไปบน connection เดิมไม่เห็นข้อมูล)
- `withPlatform` เห็นทั้ง 2 org

`packages/db/test/rls-coverage.test.ts` (**gate ของ ADR-0006** — การ์ดถัดไปทุกใบต้องผ่าน):
- ทุกตารางใน schema `public` ที่มีคอลัมน์ `org_id` (และตาราง `organization`) ต้องมี `relrowsecurity = true`, `relforcerowsecurity = true` และมี policy อย่างน้อย 1 ตัว
- ข้อความ fail ระบุชื่อตารางที่ขาด
