# T-0004 · audit_log, outbox_event, usage_event

## Goal

ตาราง append-only 3 ตัวที่ทุก feature ใช้ พร้อม helper ที่บังคับให้เขียน **ใน transaction เดียวกับการเปลี่ยนข้อมูล**

## Read first

- `docs/spec/features/foundation.md#tbl-audit_log`, `#tbl-outbox_event`, `#tbl-usage_event`
- `docs/adr/0004-channel-api.md` (ส่วน outbox)
- `docs/adr/0005-external-services-and-cost.md` §4
- `docs/adr/0003-multi-tenancy.md` (RLS)

## Deliverables

- schema 3 ตาราง ตรง spec ทุกคอลัมน์ (ไม่มี `updated_at`)
- migration (generate) + custom migration:
  - RLS `ENABLE` + `FORCE` ทั้ง 3 ตาราง; policy: `org_id = current_setting('app.org_id', true)::uuid`
    (แถวที่ `org_id is null` เห็น/เขียนได้เฉพาะ `app_platform`)
  - **append-only:** `REVOKE UPDATE, DELETE` จาก `app_runtime` บน `audit_log` และ `usage_event`;
    `outbox_event` ให้ `app_runtime` แค่ `INSERT` (worker ใช้ `app_platform` อ่าน/mark published)
  - index `outbox_event (occurred_at) where published_at is null`
- `src/audit.ts`: `writeAudit(tx, entry: AuditEntry): Promise<void>` — `before`/`after` ผ่านตัวกรองที่ตัด key ชื่อ `password`, `token`, `secret`, `token_hash` ทิ้ง
- `src/outbox.ts`: `appendOutbox(tx, event: OutboxEventInput): Promise<void>`
- `src/usage.ts`: `recordUsage(tx, input): Promise<void>`
- ทั้ง 3 helper รับ `tx` เท่านั้น (type ไม่ยอมรับ client ที่ไม่ใช่ transaction)

## Tests (เขียนก่อน)

`packages/db/test/audit-outbox-usage.test.ts`:
- ใน `withTenant(A)`: insert branch + `writeAudit` + `appendOutbox` แล้ว throw → rollback → ไม่มีแถวใดค้างทั้ง 3 ตาราง
- commit ปกติ → มีครบ, `org_id` = A
- `withTenant(B)` มองไม่เห็น audit ของ A
- `app_runtime` `UPDATE`/`DELETE` audit_log → permission denied
- `writeAudit` กับ `after: { password: "x", name: "y" }` → เก็บแค่ `name`
- `rls-coverage.test.ts` จาก T-0003 ยังผ่าน (ตารางใหม่ถูกตรวจอัตโนมัติ)
