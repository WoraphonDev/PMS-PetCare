# T-0031 · apps/api Docker image

## Goal

Image ของ API ที่รันได้จริง: bundle `apps/api` + workspace packages เป็น JS ด้วย tsdown แล้วรันบน `node:24-alpine` ด้วย user non-root
(แยกออกจาก T-0002 ตาม Q-0010)

## Read first

- `docs/adr/0001-stack.md` (Runtime, Container)
- `docs/tasks/T-0002.md` (`src/main.ts`, `src/worker.ts`)
- `docs/questions.md` Q-0010

## Deliverables

- `apps/api/tsdown.config.ts`: entry `src/main.ts` + `src/worker.ts` → `dist/`, ESM, platform node, target `node24`
  - bundle workspace packages `@app/*` (ไม่ต้อง build แยกทีละ package); third-party deps เป็น external
  - ต้อง emit decorator metadata (Nest DI) — ใช้ `unplugin-swc` ที่มีอยู่แล้วเป็น plugin ถ้า tsdown ทำเองไม่ได้
- `apps/api/package.json`: scripts `build` (tsdown) และ `start` (`node dist/main.js`)
- `apps/api/Dockerfile` (build context = repo root):
  - build stage: `node:24-alpine`, corepack pnpm, `pnpm install --frozen-lockfile`, `pnpm --filter @app/api build`, `pnpm deploy --filter @app/api --prod /out`
  - runtime stage: `node:24-alpine`, `NODE_ENV=production`, copy `/out` + `dist/`, `USER node`, `EXPOSE 3000`,
    `HEALTHCHECK` เรียก `GET /api/v1/health`, `CMD ["node", "dist/main.js"]`
  - `ARG BUILD_SHA` → `ENV BUILD_SHA`
- `.dockerignore`: `node_modules`, `.git`, `.turbo`, `**/dist`, `.env*` (ยกเว้น `.env.example`), `docs`

## Tests (เขียนก่อน)

- `apps/api/test/build/bundle.test.ts` (รันหลัง build): `dist/main.js` และ `dist/worker.js` มีอยู่; ไม่มี import ที่ชี้ไป `@app/` หรือไฟล์ `.ts`;
  ไม่มีข้อความจาก `.env` ใน dist
- smoke ใน *Done when*: image รันได้, `/api/v1/health` ตอบ `version` = `BUILD_SHA` ที่ส่งเข้าไป, process ไม่ได้รันเป็น root

## Done when

```bash
pnpm --filter @app/api build
pnpm --filter @app/api test
docker build -f apps/api/Dockerfile --build-arg BUILD_SHA=t0031 -t pms-api:t0031 .
docker run -d --rm --name pms-api-smoke -p 127.0.0.1:3999:3000 --env-file .env.example pms-api:t0031
curl -fsS http://127.0.0.1:3999/api/v1/health   # {"status":"ok","version":"t0031"}
test "$(docker exec pms-api-smoke id -u)" != "0"
docker stop pms-api-smoke
pnpm verify
```
