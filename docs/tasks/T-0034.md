## Deliverables

- `packages/db/src/tenant.ts`: proposed `withTenantTx(tx, orgId, fn)` ตั้ง local context บน existing tx ไม่เริ่ม transaction ใหม่; runtime-role guard ต้องพิสูจน์ก่อน DML
- org public `index.ts`: proposed `bootstrapOrganization(txContext, input)` สร้าง organization/branch/7 branch_hours/owner; subscription public `index.ts`: proposed `startFreeSubscription(txContext, orgId, now)` อ่าน active mvp_free และสร้าง subscription
- paths subscription module/test และ public indexes เป็น new files ใน actual apps/api module layout; org ปัจจุบันมี permissions.ts เท่านั้น ไม่สมมติว่ามี service แล้ว
- ไม่มี endpoint/Nest module registry entry ถ้าไม่จำเป็น; ไม่เพิ่ม grant/schema/session/identity insertion; transaction ownership อยู่ caller

## Tests (เขียนก่อน)

- Real Postgres runtime-from-start identity fixture + all bootstrap rows commit/rollback; inject failure ทุก stage รวม weekday rows และ subscription FK
- missing/wrong org context RLS denial; wrong connection fail closed; runtime cannot escalate to platform/migrator
- max:1 same-PID after commit/application throw/SQL abort local org cleared; other-org data invisible; expected branch defaults/owner scope/mvp_free plan read-only
- independent review subscription requires human approval; no claimed production grants inspection
