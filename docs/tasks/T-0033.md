## Deliverables

- Identity repository: `issueEmailVerification(tx, userId, now)` / `consumeEmailVerification(tx, token, now)` และ transaction-bound issuance public export; signed token ใช้ pinned Better Auth path พร้อม authenticated nonce ที่ spike พิสูจน์ก่อน implementation
- existing verification namespace/digest/expiry/delete-on-consume + user FOR UPDATE ตาม spec; no migration/new columns; no HTTP route/real email/global login switch ในใบนี้
- sender collector API แยก capture กับ dispatch ที่เรียกได้หลัง commit เท่านั้น request-local ไม่ shared; narrow clock behavior characterization

## Tests (เขียนก่อน)

- Real Postgres issue/rotate/consume, missing/duplicate state invariant, no raw token storage; valid/invalid/expired exact boundary/reused/replaced/wrong-purpose/change-email rejection
- same-second rotation ได้ distinct token; reset/2FA namespace ไม่ชน; rollback issue/consume ไม่เปลี่ยน state/emailVerified; expired cleanup coexistence
- parallel verify exactly one success, resend/verify ทั้ง lock orders, parallel resend last rotation wins; no native session created
- pinned source spike ต้องยืนยัน authenticated nonce/signature verification และ Db|Tx composition; ถ้า library public API ไม่รองรับ ให้ question ก่อนเลือก implementation
