## Goal

## Deliverables

- In `two-factor.test.ts`, give each `it(...)` that chains several HTTP calls (login → 2FA enrolment/verification → further calls) an explicit per-test timeout as the third argument of `it`, using one named constant at the top of the file (e.g. `const MULTI_STEP_TIMEOUT_MS = 20_000;`). Observed failing tests: "trusted device bypasses 2FA within 30 days…" and "disable requires password AND code…"; apply the constant to every test of the same multi-step shape in the file so the next slowest test does not become the new flake.

- If the timeout is caused by something other than slow-but-correct steps (e.g. a hang from fake timers left on, or an unawaited promise) → fix that cause inside this file only if it does not change what is asserted; otherwise write a question.
