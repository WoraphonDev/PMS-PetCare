# T-0001 · Workspace packages: config, domain, contracts

## Goal

สร้าง 3 package พื้นฐานให้ทุกการ์ดถัดไปใช้: preset tsconfig, `@app/domain` (กฎธุรกิจล้วน + clock), `@app/contracts` (zod + error envelope กลาง)

## Read first

- `docs/adr/0001-stack.md` (ตาราง Decision)
- `docs/adr/0002-modular-monolith.md` (layout + กฎขอบเขต ข้อ 4)
- `docs/spec/01-conventions.md`
- `docs/spec/features/foundation.md#errors`

## Deliverables

- `packages/config/` (`@app/config`): `tsconfig.node.json`, `tsconfig.react.json` ที่ extend `../../tsconfig.base.json`
- `packages/domain/` (`@app/domain`):
  - `src/clock.ts`: `export interface Clock { now(): Date }`, `export const systemClock: Clock`, `export function fixedClock(iso: string): Clock`
  - `src/index.ts` re-export
  - biome override: ห้าม import `@app/*` และ module ของ Node ที่ทำ I/O (`node:fs`, `node:net`, `node:http`, `pg`) ใน `packages/domain/src/**` (`noRestrictedImports`)
- `packages/contracts/` (`@app/contracts`):
  - `src/errors.ts`: `ErrorCode` (zod enum ของทุกรหัสในตาราง `#errors` — ครบทุกตัว, ชื่อตรงตัว), `ErrorResponse` schema ตาม envelope, `errorHttpStatus: Record<ErrorCode, number>` ตามตาราง
  - `src/index.ts` re-export
- ทุก package มี script `typecheck` (`tsc --noEmit`) และ `test` (`vitest run`)
- root `package.json`: ไม่ต้องเปลี่ยน scripts (turbo เรียก `typecheck`/`test` ของแต่ละ package)

## Tests (เขียนก่อน)

- `packages/domain/test/clock.test.ts`: `fixedClock` คืนเวลาเดิมทุกครั้ง; ISO ผิดรูป → throw
- `packages/contracts/test/errors.test.ts`: `ErrorCode.options` ตรงกับรายการใน spec **ทุกตัว** (เขียนรายการเป็น literal ใน test); `errorHttpStatus` ตรงกับ HTTP ใน spec; envelope ตัวอย่างใน spec ผ่าน `ErrorResponse.parse`
