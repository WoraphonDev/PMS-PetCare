## Design (technical defaults confirmed by the human on merge)

### `packages/api-client` (`@app/api-client`)

- `createApiClient({ baseUrl, fetch? })` → a client whose `request(spec, input)` sends JSON with `credentials: "include"`, adds `X-Org-Id` when `input.orgId` is given, and:
  - 2xx → parses the body with the endpoint's response schema from `@app/contracts` (204 → `undefined`); a body that does not match → `ApiError` with code `INTERNAL` (never returns unvalidated data);
  - non-2xx → parses `ErrorResponse` → throws `ApiError { status, code, message, details }`; an unparseable error body (e.g. an HTML page) → `ApiError` `INTERNAL` with the HTTP status;
  - network failure (`fetch` rejects, including offline) → `ApiError` `INTERNAL`, `status: 0`.
- Endpoints are small typed descriptors `{ method, path, response, body? }` in `src/endpoints/<module>.ts`, built from contract schemas. **This card adds only `me.get`** (`GET /me`). Later cards add the endpoints their screens use. The client never invents a field: request/response types are always `z.infer` of contracts.
- Depends only on `@app/contracts` + `zod` (ADR-0002 rule 4). No React in this package. Biome enforces it: `packages/api-client/**` may import only `@app/contracts`, and `packages/ui/**` no `@app/*` package (root `biome.json` overrides).
- `src/index.ts` is a registry checked by `node scripts/check-registries.mjs` (kind `block`): the exports later cards append to sit between `// registry:start` and `// registry:end`, one complete entry per line, sorted, no blank or comment lines inside; other code may stay outside the block.

### `packages/ui` (`@app/ui`)

- `cn()` (clsx + tailwind-merge) and the shadcn `Button` as the first shared component, Tailwind v4 tokens in one `styles.css` the app imports. Further components come with the screen cards that use them.
- Exports source TypeScript (like `@app/contracts`); the consuming app's Vite/Tailwind build compiles it.

Out of scope: `apps/pms-web` and everything in it (T-0022), any endpoint other than `me.get`, other shadcn components, dark mode.

## Tests (write first)

Vitest; a stubbed `fetch` for the client (no real network); `jsdom` + Testing Library for `Button`.

- **api-client** (`packages/api-client/test/`):
  - `me.get` 200 → parsed `MeResponse`; request is `GET {baseUrl}/me` with `credentials: "include"` and `Accept`/`Content-Type` JSON;
  - `orgId` given → `X-Org-Id` header; not given → no header;
  - a body sent for POST/PUT/PATCH is JSON-encoded; 204 → `undefined`;
  - every `ErrorCode` from an envelope becomes `ApiError` with that code and HTTP status;
  - 2xx body that fails the response schema → `ApiError` `INTERNAL`; non-JSON error body (HTML) → `INTERNAL`; `fetch` rejects → `INTERNAL`, status 0;
  - type test: `request(meGet, …)` resolves to `MeResponse` (`expectTypeOf`).
- **ui** (`packages/ui/test/`): `cn` merges conflicting Tailwind classes; `Button` renders variants and forwards `asChild`.
