## Delivered behavior and coverage

Public JSON verify consumes the repository's single current digest atomically and returns 204 with no body/session/cookie; approved invalid/malformed/expired/reused/replaced/wrong-purpose cases return token-field VALIDATION_FAILED. Native/signed wrong-purpose tokens, signed expiry, persisted expiry, callback/change-email inputs and concurrent consumption are covered. Corrupt state and actual DB outages return sanitized INTERNAL.
Resend normalizes before validation/quota; schema-invalid requests do not count. Existing atomic dual-key limiter runs before any recipient lookup. Unknown, verified, managed and managed.invalid addresses count identically, including mixed-case historical domains. Over-email/IP quota and a disconnected real Valkey suppress rotation/send. Parallel requests allow exactly three rotations and only the current digest verifies; sender failure retains committed rotation and consumes quota.
Template uses APP_ORIGIN/verify-email#token=<encoded>; native links/tokens/callback URLs are discarded. No raw token is returned by the new HTTP/use-case/capture helpers. createAuth disables signup auto-login and verification auto-login/sign-in sends; transaction-bound signup callback captures approved state. No signup route or global login-verification gate was added. Native HTTP handler remains unmounted.
Identity's existing public session-policy wiring ignores supplied cookies on just the two public verification routes, including must-change-password sessions, preventing unrelated session reads/refreshes/denials. Tests assert unchanged session rows, no Set-Cookie/body/location on success, and ignored malicious callbacks.
Request-local collectors hold messages until the outer transaction resolves, isolate simultaneous captures, dispatch once, and discard rollback. Existing real-DB baseline tests additionally exercise deferred commit failure and never-before-commit delivery, repository lock races, namespace ownership and injected expiry boundaries. Public signup capture returns void and composes with the existing after-commit dispatcher. Tests inspect HTTP logs and audit rows for token/PII/link/provider redaction; no analytics instrumentation was added.
