# 00 — Overview

> สถานะ: **MVP scope accepted (2026-10-19)**

## 1. ผลิตภัณฑ์

**PMS-PetCare** — ระบบบริหารร้าน Grooming · Pet Hotel · Daycare แบบ SaaS
รายได้: subscription plan ของร้าน · ลูกค้าของร้านจ่ายเงินให้ร้านโดยตรง (PMS บันทึก ไม่รับเงินแทน)

| ส่วน | ผู้ใช้ | เฟส |
|---|---|---|
| PMS web (PWA) | เจ้าของร้าน, ผู้จัดการ, พนักงานหน้าร้าน, groomer, ผู้ดูแลสัตว์ | MVP |
| LINE แจ้งเตือน (OA ของร้าน) | ลูกค้าของร้าน | MVP |
| Platform admin | ทีมเรา (จัดการร้าน + แพ็กเกจ) | MVP |
| LINE จองผ่าน LIFF | ลูกค้าของร้าน | เฟส 2 |
| Channel API (OTA ภายนอกเชื่อม) | Marketplace / OTA | เฟส 3 |

**นอกขอบเขต repo นี้:** Marketplace web, Mobile app native, การรับเงินแทนร้าน

## 2. บริการของร้าน

- **Grooming** — นัดเป็นช่วงเวลา ตาม groomer, ราคาตามขนาด/สายพันธุ์/ขน
- **Hotel** — พักค้างคืน ตามประเภทห้อง, check-in / check-out
- **Daycare** — ฝากรายวัน / แพ็กเกจหลายวัน, ความจุต่อวัน

## 3. MVP

### 3.1 ลูกค้า สัตว์ บริการ ราคา
ทะเบียนลูกค้า, สัตว์เลี้ยง (ชนิด, สายพันธุ์, ขนาด, น้ำหนัก, ข้อควรระวัง), วัคซีน,
แคตตาล็อกบริการและราคาตามขนาด/สายพันธุ์/ขน, แพ็กเกจ

### 3.2 Grooming
ตารางนัดตาม groomer/เวลา, สถานะงาน (นัด → มาถึง → กำลังทำ → เสร็จ → รับกลับ), รูปก่อน-หลัง, บันทึกงาน

### 3.3 Hotel + Daycare
ห้อง/ประเภทห้อง/ความจุ, การจองพัก, daycare รายวันและแพ็กเกจ, check-in/out, บันทึกการดูแลระหว่างฝาก (อาหาร ยา รูป)

### 3.4 ชำระเงิน + รายงาน
บิลจากบริการ, มัดจำ, **บันทึกการชำระ** (เงินสด / โอน / PromptPay QR ของร้าน / บัตรผ่านเครื่องของร้าน) + แนบสลิป, ใบเสร็จ,
รายงานยอดขายรายวัน/เดือน ตามบริการ/พนักงาน/วิธีชำระ

### 3.5 LINE แจ้งเตือน
ร้านเชื่อม LINE OA ของตัวเอง, ลูกค้าผูก LINE กับโปรไฟล์ (ลิงก์/QR จากร้าน),
แจ้งยืนยันนัด, เตือนก่อนถึงนัด, สถานะงาน grooming เสร็จ, รูป/อัปเดตระหว่างฝาก

### 3.6 พื้นฐานที่จำเป็น
- สมัครร้าน, login พนักงาน (email + รหัสผ่าน, ลืมรหัสผ่าน), เชิญพนักงาน
- organization / branch, เวลาเปิด-ปิด, วันหยุด, ตั้งค่าร้าน (ชื่อ, โลโก้, PromptPay ID, ข้อมูลใบเสร็จ)
- บทบาท: `owner` · `manager` · `front_desk` · `groomer` · `caretaker` (สิทธิ์ละเอียดใน feature spec)
- หน้า "วันนี้" (dashboard): นัด grooming, check-in/out, สัตว์ที่อยู่ในร้าน
- audit log สำหรับเงินและสิทธิ์
- platform admin: รายชื่อร้าน, เปิด/ปิดแพ็กเกจ, ระงับร้าน
- PDPA: consent, ขอ export/ลบข้อมูลลูกค้า
- ภาษาไทยอย่างเดียวใน MVP (โครง i18n รองรับภาษาอื่น)
